Sistema de Cadastro de Motores

Documentação técnica da aplicação monolítica em Python desenvolvida para gestão de dados técnicos de motores elétricos em memória.

Sobre o Desenvolvimento

Este projeto foi desenvolvido durante as atividades de formação técnica no CentroWEG, unidade educacional fruto da parceria entre o SENAI e a WEG, localizada em Jaraguá do Sul - SC.

O objetivo da atividade foi aplicar conceitos fundamentais de lógica de programação, modularização com funções e manipulação de estruturas de dados (listas e dicionários) simulando o catálogo técnico de motores industriais (como as linhas W22 e W21).

Ficha Técnica do Projeto

  • Instituição: SENAI / CentroWEG
  • Localidade: Jaraguá do Sul, Santa Catarina
  • Linguagem: Python 3
  • Arquitetura: Monolítica (arquivo único)
  • Persistência: Em memória (Arrays/Listas)

Como o Código Funciona

O programa opera sem banco de dados externo, utilizando variáveis globais e funções separadas por responsabilidade (CRUD):

Estrutura de Dados

Lista & Dicionários

A lista global motores = [] atua como banco de dados volátil. Cada motor é armazenado como um dicionário contendo id, modelo, fabricante, potencia_cv, tensao_v e rpm.

Create & Read

cadastrar_motor() & listar_motores()

Coleta os dados via terminal, valida entradas numéricas com try/except, gera um ID sequencial automático e exibe os registros formatados em tabela no console.

Update & Delete

editar_motor() & excluir_motor()

Utilizam a função auxiliar buscar_motor_por_id() para localizar o registro na lista, permitindo atualizar atributos individuais ou remover o item com confirmação.

Ambiente de Teste

popular_dados_teste() & menu()

Antes de iniciar o loop principal while True, o sistema pré-carrega 3 modelos reais (WEG e Siemens) para agilizar os testes de listagem e edição.

# Lista (array) global que funciona como banco de dados em memória
motores = []
proximo_id = 1

def cadastrar_motor():
    global proximo_id
    print("\n--- CADASTRAR NOVO MOTOR ---")
    modelo = input("Modelo/Referência: ").strip()
    fabricante = input("Fabricante (ex: WEG, Siemens): ").strip()

    try:
        potencia_cv = float(input("Potência (CV): ").replace(",", "."))
        tensao_v = int(input("Tensão nominal (V) [ex: 220, 380]: "))
        rpm = int(input("Rotação (RPM): "))
    except ValueError:
        print("\n[ERRO] Potência, tensão e RPM devem ser valores numéricos.")
        return

    motor = {
        "id": proximo_id,
        "modelo": modelo,
        "fabricante": fabricante,
        "potencia_cv": potencia_cv,
        "tensao_v": tensao_v,
        "rpm": rpm
    }

    motores.append(motor)
    proximo_id += 1
    print(f"\n[SUCESSO] Motor ID #{motor['id']} ({modelo}) cadastrado!")

def listar_motores():
    print("\n--- LISTA DE MOTORES CADASTRADOS ---")
    if not motores:
        print("Nenhum motor cadastrado no momento.")
        return

    print(f"{'ID':<4} | {'Modelo':<18} | {'Fabricante':<14} | {'Potência':<10} | {'Tensão':<8} | {'RPM':<6}")
    print("-" * 74)
    for m in motores:
        print(
            f"{m['id']:<4} | {m['modelo']:<18} | {m['fabricante']:<14} | "
            f"{m['potencia_cv']:<7.1f} CV | {m['tensao_v']:<5} V  | {m['rpm']:<6}"
        )

def buscar_motor_por_id(motor_id):
    for motor in motores:
        if motor["id"] == motor_id:
            return motor
    return None

def popular_dados_teste():
    global proximo_id
    exemplos = [
        {"id": 1, "modelo": "W22 IR3 Premium", "fabricante": "WEG", "potencia_cv": 5.0, "tensao_v": 380, "rpm": 1750},
        {"id": 2, "modelo": "1LE0", "fabricante": "Siemens", "potencia_cv": 10.0, "tensao_v": 220, "rpm": 3500},
        {"id": 3, "modelo": "W21 Trifásico", "fabricante": "WEG", "potencia_cv": 1.5, "tensao_v": 380, "rpm": 1150},
    ]
    motores.extend(exemplos)
    proximo_id = 4
